# P21 同构基底：设计取舍记录

本文件记录 `data/isomorphism_p21.json` 及其运行时（`plugins/isomorphism_p21.py`）在实现时
做过的取舍，以及为什么没有采用另一条路。方案原稿是 Gemini 的《PYBOT 量子算法 7》，这里是
落到本代码库后的裁决。

## 1. 一个联合矩阵，不分槽位各建一套

**取**：实体 / 动作 / 后果 / 钩子 / 辅助词（共 668 个）放进同一个句级共现矩阵。

**不取**：四个槽位各建一个子空间再拼接。理由：槽位标签是排版需要，不是语义边界——
"电流" 在实体位和后果位都出现过；分槽会人为切断同词在不同槽位的载荷，且矩阵变小后
PPMI 的边际平滑更不稳。跨槽位的相容性（实体↔动作、动作↔后果）正是要量的东西，
只有同一空间里才能算余弦。

## 2. 词–词 PPMI + 截断 SVD，不做 NMF / 概率主题模型

**取**：句级共现 → 对称 PPMI（α=0.75 边际平滑、小于 0 截断）→ 在 `AᵀA` 上做块幂迭代，
纯标准库，固定种子 `0x21B07`（十进制 138823）。

**不取**：

- NMF：需要外部依赖（scipy/sklearn），且分解结果对初始化敏感，破坏"两机重跑逐字节一致"。
- LDA/主题模型的 KDE：需要采样、随机性大，且主题向量不是稀疏可读的物理量。
- 直接对共现矩阵做 SVD：矩阵 668×668 不算大，但 `AᵀA` 上迭代保证半正定，收敛判据干净
  （PPMI 截断后有负特征值，直接对 `A` 迭代会得到带符号的 Rayleigh 商，残差检验要特别处理；
  这里两样都做了，`meta.residual_max` 是 9.47e-3）。

## 3. k = 12 固定，不按能量阈值自适应

谱很平：σ ≈ 60.4 / 32.2 / 28.9 … 第 12 维仍 19.5，累计能量只有 0.2759，任何 0.8/0.9 的阈值
都会把 k 推到几十上百，失去"每维可人工读一个物理主题"的意义。固定 12 维，同时把 16 维谱
写进 `meta.singular_values` 供审计；`axes_audit` 给出每维正负两端载荷最大的 6 个字粒。

轴读法（实测）：轴0 电子/速度/原子/质量；轴1 电流/温度/线圈 vs 动量/速度；轴2 电流/线圈/电路
vs 气体/分子/原子；轴3–4 振幅/频率/波长；其余轴上多为电路与光学元件。像物理主题，不像
分词噪声——这是保留 12 维的主要证据。

## 4. 符号锁按轴做，不按词做

SVD 的特征向量符号任意。约定：**每一维上载荷绝对值最大的字粒取正**。写成脚本里的断言，
重建不一致即失败。按词锁没有意义——同一维里不同词的载荷本来就该有正有负。

## 5. 相容乘子"替换"既有的 ×0.35，且乘子按池内分位定

`_evaluate_path` 里抽象 OOV 实体原先一律乘 ×0.35（粗罚）。P21 打开时改为
**池内分位乘子**：`1.0 + 1.2·(pct − 0.5)`，夹到 [0.6, 1.6]，pct 是该路径的
相容分在同一请求所有受评路径里的分位。

- 这是**替换**：×0.35 不再叠加，否则两项相乘会把 OOV 路径压到接近零。
- 为什么不用固定中心：PPMI 余弦的绝对尺度没有可比含义，开发集 score 中位 0.016、
  p90 0.082，固定中心 0.25 导致全池 96.7% 的路径都挨罚，乘子只是整体压高度，
  没有用上排序信息。分位乘子免标定：换语料、换领域都不用重调；池里只有一条路径时
  pct=0.5、乘子恰好 1.0，不再出现"单条路径被固定中心压低"的无依据惩罚。
  `engine.multiplier`（固定中心版本）保留给单路径 API 与测试，运行时不再乘它。
- 实测（`data/p21_calibration.*`，56 问句 × 3 nonce）：312 条路径受评，乘子中位
  1.0，37.5% 高于 1、25% 低于 1；开关改变 127/168 条输出，用户实体入句 77→82。

## 5b. 池内全局机制项：让 P21 对所有问句生效

原方案只在"用户实体"分支里用乘子，语料内实体的问句完全轮不到它。现在多一层
池内重排（`P21Context.rerank_pool`）：

- 问句语义中心 = 实体向量（OOV 走四源投影）⊕ 谓语向量（OOV 走字面重叠投影，
  见 §5c），按 0.55/0.45 合成；
- 每条路径相似度 = 0.6·cos(问句中心, 动作+后果机制) + 0.4·cos(谓语向量, 动作)；
- 乘子 `exp(0.18·(pct − 0.5))`，范围约 [0.914, 1.094]，只改相对排序。

它只作用于候选集内已通过相位/术语闸门的路径，不引入新字粒，也不改变空白阈值。
影响幅度小于相容乘子一个量级，是为了"常在场"而不是"能翻盘"。

## 5c. OOV 谓语投影：字面重叠 + 通用动作重心

句级语料里"下跌/变凉/发霉"这类谓语常常不在字库。`P21Engine.verb_vector` 取与它们
共享汉字比例最高的 3 个动作向量加权平均，再加 0.15 权重的动作重心，Top-3 稀疏化；
语料内谓语直接取库向量。这样"股票**下跌**"里的"下跌"至少落到"下沉/变化"附近，
而不是被丢掉（原实现只把谓语当实体投影的加权来源，谓语本身没进空间）。

## 6. OOV 投影必须稀疏化，且要有兜底

`oov_vector` 取四路来源（查询动词 0.45 / 学习边 0.30 / 原型词 0.20 / 通用动作质心 0.10），
只保留绝对值最大的 3 维。不稀疏化时，四路加权平均会把向量摊到几乎所有轴上，余弦趋于
常数，乘子失去区分度。四路全空时返回 `None`，调用方退回旧 ×0.35——不能因为"没有信息"
反而变成 ×1.0 的抬举。

## 7. 相位带宽：只对有可靠统计的字粒生效

字库的 `phase_deg` 是首现句相位，噪声大。`data/phase_bandwidth_p21.json` 统计每个字粒在全部
出现句上的圆周均值 μ 与集中度 R，可靠性 `r = R²·n/(n+10)`：出现两三次的字粒 r 很小，
对齐分几乎退回纯余弦；出现多的字粒按 μ 对齐。`align = (1−r)·cos(φ−target) + r·cos(μ−target)`，
全局仍在 [−1, 1]。

## 8. 段落的实体锁与类比门

- 第 2 句（类比句）打分乘 `(0.35+0.65·D01)·(0.25+1.50·S01)`，其中
  `D01 = (1−cos(锚实体, 候选实体))/2`、`S01 = (cos(锚机制, 候选机制)+1)/2`，乘数落在
  [0.0875, 1.75]：同实体同机制接近 1.75，同实体异机制约 0.44。目的只有一个：
  远实体 / 近机制优先，跨域类比不禁止。
- 第 3 句（收束句）若实体在字库里，直接锁回锚点实体；同时闭合相似度改为
  `0.5·相位闭合 + 0.5·((余弦+1)/2)`，让同构向量参与收束选择。

## 9. 诚实诊断只记录，不参与打分

每题结束后对存活路径算两个量：

- `residual`：后果向量对 span{实体向量, 动作向量} 的正交残差占比——越大说明后果带来的
  信息越"独立于"实体与动作，可能是真信息，也可能是向量没学到关系。
- `entropy`：Top-M 归一化熵——越大越接近均匀分布，即系统对这句话没有偏好。

两者都只写进 `result["p21_diagnostics"]`，不改任何权重。在没有标注的情况下，把"不确定"
从"假装确定"里分出来是第一位的，但用它调分等于自证。

## 9b. 表征选型：留出共现回填实验

`scripts/eval_isomorphism_p21.py` 把语料按行切 9:1，用前 90% 建矩阵，在留出 10% 的
句子上做"已知一个词，从 4 个同槽词里选真正同现的那个"（随机基线 0.25）：

| 变体 | 词→后果 top1（104 题） | 词→动作 top1（859 题） |
|---|---|---|
| 句级等权, k=12（现线上） | 0.490 | 0.368 |
| 句级等权, k=24 | 0.500 | 0.348 |
| ±8 字距离加权, k=12 | 0.452 | 0.335 |

结论：现线上配置在两个任务上都不差于替代方案（k=24 只在 104 题的后果题上高 1 个
百分点、动作题低 2 个百分点；距离加权两题都低）。**不换产物**。三元组题（已知
实体+动作选后果）留出集只有 11 题，只作旁证，不参与选型。结果存
`data/p21_eval.json` / `.md`。

## 9c. 段落盲评：赢在语料外实体，语料内持平

`scripts/ab_p21_blind.py` 生成 40 组同 nonce 段落（16 组语料外实体问句 + 24 组语料内），
A/B 按问句哈希摆位、钥匙单存；评分由 Claude 模型完成（同 P16 的做法，不是人评），
只评"是否贴题、是否顺畅"，不评物理正确性。

| | 基线 | 开启 P21 |
|---|---|---|
| 均分（1–5） | 3.00 | 3.63 |
| 语料外实体 16 组 | 2.19 | 3.69 |
| 语料内实体 24 组 | 3.54 | 3.58 |

配对平均差 +0.625；胜负：P21 15 胜 / 基线 2 胜 / 平 23。分差几乎全部来自
"首句主语是不是问句里的实体"——正是 P16 的实体漂移问题；语料内问句两组持平，
与全局机制项刻意压小的幅度一致。评者是设计者模型的同族，存在同源偏置，
结论以人评为准。材料：`data/ab_p21_pairs.md`（盲评表）、`data/ab_p21_key.json`
（钥匙）、`data/ab_p21_scores_model.jsonl`（评分）、`data/ab_p21_report.md`（汇总）、
`data/ab_p21_proxy.md`（机械指标：留白 0/0、三句齐 0/0、实体锁定率 0.667→0.658、
句内重复 0/0）。

## 10. 不碰的东西

- P15 字库逐字节不动；P21 全在独立产物里，`--check` 保证重建一致。
- 默认全关：`PrintRequest.use_isomorphism` / `ParagraphRequest.use_isomorphism` 默认 `False`，
  总线路由不主动打开；关时与旧版逐字节一致（有测试）。
- 不做运行时 LLM 调用（`QBOT_MAX_LLM_CALLS=0` 不受影响），无新依赖。
- 历史产物只增不改：两个构建脚本遇到已存在的输出文件一律拒绝覆盖，要换产物用新文件名。
