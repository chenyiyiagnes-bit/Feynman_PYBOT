# omega_mind — one-page spec

规则驱动的“右脑”状态层。左脑（事实）可以是 PyBot，也可以是内置小知识库；本层只负责**跨轮情绪、人格一致性与表达风格**，不改写事实。

## 1. 数据流

```
text ──▶ Appraisal（26 个评估器，带习惯化）
      ──▶ AffectState（7 维，泄漏积分器，回到基线）
      ──▶ Policy（状态 → StyleDirective）
      ──▶ Renderer（base_reply + directive → 台词；数字/名词不动）
      ──▶ MemoryTiers（每轮一条 episode）+ RelationshipGraph（每轮一个 touch）
      ──▶ CubeState（强激活 ≥0.75 自动转一面）+ Dreamer（≥8 条未整理时整理）
      ──▶ CubeView（只读投影，用于显示）
```

cubie 只做“这件事对我意味着什么”的打分；魔方既有只读投影（`view.py`），
也有真实状态（`cube.py`，26 块会动）——两者读的是同一套 26 个名字。

## 2. 状态维度（7）

| 维度 | 范围 | 基线（generic / feynman） | 半衰期 τ |
|---|---|---|---|
| dopamine 好奇/愉悦 | 0–1 | 0.30 / 0.60 | 90s / 120s |
| cortisol 压力 | 0–1 | 0.30 / 0.12 | 240s / 60s |
| valence 愉悦度 | -1–1 | 0.0 / 0.15 | 150s |
| arousal 唤醒 | 0–1 | 0.30 / 0.40 | 90s |
| affinity 亲密 | 0–1 | 0.20 / 0.25 | 1 天 |
| defensiveness 防御 | 0–1 | 0 / 0 | 90s / 45s |
| energy 精力 | 0–1 | 0.80 / 0.85 | 1 小时 |

所有维度硬性 clamp；慢变量（affinity）不因一次事件归零。

## 3. 26 个 cubie

6 核心（ego/id/logic/intuition/superego/memory）＋ 12 棱 ＋ 8 角。
每个 cubie 有：面（F/B/L/R/U/D）、极性、触发正则、状态增量。
同一 cubie 在 3 轮窗口内重复触发，增益按 0.6ⁿ 衰减（防漫画化）。
窗口按轮号滑动：超出 3 轮的旧触发自动过期，隔一段时间再说同一句话会恢复满强度。

## 4. 风格指令（Policy 输出）

tone（warm/neutral/cold/sharp）、warmth、directness、verbosity、humor、tempo、expression、prefix/ending 池、激活列表。
渲染器实际消费四类字段：warmth 过滤结尾池（冷时只留句号，暖时偏好软结尾）；
verbosity ≤0.30 进入简洁模式，丢掉前缀和俏皮结尾；humor + expression 决定可选的表情标签池；
prefixes/endings 正常时照旧使用。directness 与 tempo 只作为下游提示（如语速/姿态），不直接改字。

## 5. 费曼参数

- 被纠错 → 多巴胺 +0.30，不触发羞耻（`corner_shame` 禁用）；
- 掉书袋/权威压人 → 皮质醇 +0.35，`tone=sharp`；
- 客套模块禁用，politeness=0.1；
- 口头禅池：等等 / 嘿 / 说真的。

## 5.5 检索与挑战（第 3 步）

- 左脑顺序按语言分开：中文 provided → 中文 `feynman_kb` → `builtin_kb` → 兜底句；
  英文 provided → 英文 `feynman_kb` 译文层 → PyBot → 英文 `builtin_kb` → 兜底句。
- `feynman_kb`：字符二元组 TF-IDF，覆盖率 ≥0.30 且必须命中标题/标签/别名/不变量；否则明确弃答。
  三个以上词组成的问句不能只靠一个命中词取分（彩虹色散题不许被「颜色」标签或标题粘连 bigram
  「总是」带进轶事卡/阻尼卡）；一问一主题的单 token 问句不受此限。
  查询权重只统计语料里存在的词，标题词命中两个以上有少量加分；中文按意图补同义词
  （"浮在水上"→"浮力 漂浮"），英文用词级 token + 轻量词干。
  三条拒答护栏：英文闲聊、中英文个人经历问题、英文第三人称 why（除非点名费曼）。
- 费曼「人生与艺术」卡包（`knowledge/feynman_life_art.jsonl` + `data/kb_en/feynman_life_art_en.jsonl`）：
  画画、花与科学、邦戈鼓/桑巴、不懂装懂、发现的乐趣、社会期待、开锁、失去阿琳，八张三语对齐卡。
  中英 id 一一对应；英文层是译文摘要，不冒充费曼原话。
  `lookup()` 返回 `score`、`margin`（与第二候选差距）、`considered`；
  `margin` 只在候选数 ≥2 时存在，候选数被压到 1 时没有可比对象。
  金标集 `tests/test_retrieval_quality.py`：65 个正例 + 10 个必拒陷阱，改权重先跑它。
- 联想边（`assoc.py` + `data/assoc/assoc_edges.jsonl`）：卡片之间存带类型的边——同一个方程
  （带 `mapping` 符号对应表，从另一端说话时自动对调）、同机制、前提-结论、边界、张力
  （两条都成立，写出缺的条件）、退化极限
  （`limit_of`，带 `condition`，只从特例一侧说）、同域。人工边必须写一句机制；同方程、同机制、
  边界和张力还必须写一句最强差异。句子必须单句、中文总长 ≤120 字（英文 ≤420 字符）。引擎在卡片
  作答后追加最多一句（`brief` 略过），**不改变 `source`、`score` 和 `alternatives`**；边界边
  允许指向答案的第二候选（它就是为「别和它混了」写的）。上一轮也由卡片作答且两卡之间已有边时，
  这一句改成「接着刚才的……」；隔轮、闲聊或同题重问都不接。
  机器候选（`scripts/mine_assoc.py` → `origin=cooccur`）只落在 `scripts/data/`，不得出现在
  运行时文件里，也不出声。中英是两条平行分支：每条出声的边都要写英文机制（同方程/同机制/边界
  还要英文差异，同方程另需英文符号表，极限需英文条件），英文句不从中翻英；英文分支只在对方卡
  有英文名时出声，绝不拿中文句兜底。
  用户只回一句"为什么？"（不带新主语）且上一轮是卡片作答时，沿上一张卡的**前提边**（`premise`）
  走一层：正文取前提卡自己的答案，前面加已确认的机制连接；`avoid` 防止两条前提边循环；没有前提边
  就照常检索。
  类比换写（`AssocGraph.recast`）：用户回一句“没懂/不明白/换个说法/打个比方”（≤24 字，中英各自
  匹配），且上一轮是卡片作答时，不重复原答案，只沿已确认的 `same_mechanism` / `same_equation`
  边换一种说法：正文说“它和某张卡是同一个机制：…”，再补“这个比方到哪儿就不成立：…”。
  只有机制和差异两半都写全的边可用；同一张卡在一轮之内不重复换写（`_recast_seen`），
  问到新东西即清空；没有可用的边就照常回答，不硬凑。`source` 写成 `analogy:<edge key>`。
  好奇提问（`feynman_kb.Lookup.question`）：仅当左脑姿态是 `explore` 时考虑，且每题一行，
  与锚点、联想句共用同一个尾位（锚点 > 联想 > 提问）。两种来源：检索前两名分差 <
  `QUESTION_MARGIN=0.06` 时用两篇真卡标题反问“你想问的是「A」还是「B」”；当前卡有已确认
  前提边时提示“底下还有一层，想往下走就问为什么”。提问冷却 3 轮（`QUESTION_COOLDOWN`）；
  `answer`/`careful` 姿态从不反问。英文分支只用英文标题，标题含中文则整句不说。
  返回抑制（`lookup(inhibit=...)`）：最近 3 轮说过的卡在排序时乘 `INHIBIT_FACTOR=0.94`，
  只用于打破近似平票；降权前先检查降完仍过门槛，所以不会把有把握的回答降成未命中，
  单候选时不动。原样重复同一问题不抑制。被降权卡写入 `Lookup.inhibited` 审计。
  数量级锚点（`scales.py` + `data/assoc/scales.jsonl`）：按卡片存费曼给过的特征数字，每条带讲义
  出处，英文行只用费曼英文；只有问题在问大小/快慢/多少/数量级时才追加，`brief` 略过，和联想句
  共用位置且优先。锚点可带人工问法（`asks`/`asks_en`），命中后直接落到该卡——这一步**会**改变
  命中卡，是刻意的检索补充，不属于"不改来源"的联想规则。
  `tests/test_assoc.py`、`tests/test_scales.py`、`tests/test_analogy.py`、`tests/test_curiosity.py` 钉住：
  边合法性、候选隔离、单句上限、来源不变、引擎真的追加、跨轮接续、为什么走一层、锚点只在问数量级时出声、
  换写只用确认过的类比且带失效点、同一张卡不重复换写、提问只用真标题且姿态/冷却/单一尾位生效。
- 费曼「数学与计算」卡包（`knowledge/feynman_math_comp.jsonl` + `data/kb_en/feynman_math_comp_en.jsonl`）：
  路径积分小箭头、微积分直觉、自制记号、可逆计算与发热、量子模拟、纳米空间、车牌概率、心算立方根，
  八张三语对齐卡。字段只用加载器真正读取的 `title`/`text`/`tags`/`aliases`，不用
  `topic`/`triggers`/`content`；中英 id 一一对应，英文层为译文摘要。
  `tests/test_feynman_math_comp.py` 校验行数、manifest sha256、双语对齐、检索命中与引擎作答。
- 软召回：分数落在 `SOFT_SCORE=0.24` 到 `0.30` 之间、且与第二候选差距 ≥`SOFT_MARGIN=0.02`
  （或没有第二候选）时，仍以 `feynman_kb_soft:<id>` 作答，`source` 前缀标明这是弱匹配。
  调用方显式把 `min_score` 抬到 0.30 以上（左脑在压力下收紧门槛）时不走软召回，门槛就是闸。
  检索先用 `min(threshold, SOFT_SCORE)` 取候选，再由 `lookup` 判硬/软，避免 `search` 提前丢掉软档。
- 学到的经验（`learner.py`，默认落在 `data/kb_learned/`，可传 `learned_dir` 指向临时目录）：
  - 唯一事实源是追加式事件流 `experience.jsonl`（`card` / `revision` / `alias` / `archive` /
    `restore`）；`learned_cards.jsonl` 与 `learned_aliases.json` 只是给人看的物化视图。
    改规则可直接重放历史，删目录仍是完整回滚；旧两文件格式在首次加载时自动迁移成事件。
  - 比喻分两段判定：明确比喻（像/好比/想象成/就像）当轮回复后立即铸卡；宽松比较
    （相当于/等于/可以看作/比作/仿佛/好像）先进待定缓冲（最多 5 条），下一轮被复用
    （共享 ≥2 个字符二元组）或被赞美（`edge_humor ≥ 0.5`）才转正，3 轮未确认即丢弃，
    出现纠正语（不是这个意思/不对/说错了…）立即取消。指代旧话的句子（像你说的/像刚才）
    不当作新比喻。
  - 三种硬护栏：①「像你这么…」「像我们…」「像…的人」这类指人、指代的说法在判定前被剥掉，
    赞美永远不会铸卡；② 原样复述或引号引用（规范化后包含原句、相似度 ≥0.70，或引号内
    相似度 ≥0.6）是最强的显式确认，即使皮质醇高也转正；③ 皮质醇 >0.40 时，赞美与复用
    这两个间接信号不转正，候选留在缓冲里等下轮（`left_brain` 用同一个 0.40）。
  - 铸卡时把整句按标点切成子句（≥4 字，最多 4 条）一并写进 `aliases`，所以只记得比喻
    后半句（"改一封后面全得重盖章"）也能找回同一张卡，而不是只有标题前半句可搜。
  - 相似合并：新比喻与现有卡字符二元组余弦相似度 ≥0.55 时不新增，而是记一条 `revision`——
    正文换成新表述，旧文留在 `revisions`（上限 10 条），新旧说法都成为该卡别名。
  - 软上限：`MAX_CARDS=200` 是淘汰线而非拒写线。每张卡带一个粗粒度 `topic`（铸卡时取
    最接近的语料卡 kind，找不到则 `general`）。淘汰时每主题保留 floor 张
    （`max(1, min(5, MAX_CARDS // (2×主题数)))` 按效用取头部），只从其余卡里挑效用最低的；
    所有卡都受保护时才退回全局最低。效用 = 命中 + 2×被赞美 + 0.2×别名 − 0.05×天数，
    计数存 `card_stats.json`。本次会话新铸的卡有宽限期，不参加本轮淘汰；归档卡可
    `restore_card()` 恢复。
  - 睡眠合并（`dream()` 内，每次入睡最多 5 组）：同 topic、相似度在 `[0.35, 0.55)` 的
    两张卡，宿主效用至少高出 1.0 时，把被吞卡的正文加成宿主别名、把被吞卡归档
    （`reason="sleep_cluster_merge"`，带 `merged_into` 与 `similarity`）。只发 `alias` +
    `archive` 事件，**不发 `revision`**（宿主正文没变，伪造修订会污染历史）；顺序固定为
    先合并、再按容量淘汰。
  - 学到的卡片与别名都只做加法：追加文件、有上限、可审计；删除对应行即遗忘；不覆盖出厂语料。
  - 评测：`scripts/evaluate_learning.py` 三组自检（硬负例不铸卡、同一张卡的 5 种问法、
    教 5 个比喻再问），全部使用临时学习目录；`scripts/mine_bridge.py` 只离线挖
    `_ZH_BRIDGE` 候选（PPMI 文档共现），输出 JSON 供人工核对，不参与在线打分。
  - `lookup()` 除 `score`/`margin`/`considered` 外还返回 `matched`：命中的查询 token，
    用于事后定位错答，不再需要重跑检索。
- `challenge`：出题用 `entry_question`，中文评分 0.6×不变量字符覆盖 + 0.4×术语覆盖，
  英文评分用词干术语覆盖并容忍词干前缀差异；两边只在真实数量（小数或多位数）出现时乘数字系数。
  答错加多巴胺不加皮质醇，两次未答上公布 `force_invariant`。
  每个单元记录 `{asked, strong}`：答对一次即“掌握”，`next_unit` 先出未掌握的卡，
  全部掌握后才重新循环；掌握数写入 `status["mastered"]`，随存档保存。
  会话由引擎持有：`GET /api/challenge` 查状态，`POST /api/challenge` 支持 start/answer，
  进度写入存档 `challenge` 字段，切语言时迁移同一进度。

## 5.6 语言模式（第 5 步）

- `engine.language ∈ {zh, en}`，随存档保存；CLI `--lang` / `/lang`，服务器 `/api/lang`，WS 消息可带 `lang`。
- 回复语言必须与模式一致：中文模式要求回复含中文，英文模式要求回复不含中文，否则换兜底句。
- 中文模式左脑 = feynman_kb（中文索引）→ 内置中文库；英文模式左脑 = feynman_kb（`data/kb_en`
  译文索引）→ PyBot → 英文内置库。英文译文层按 `id` 覆盖 `title/text/...` 等回复字段，
  中文卡仍是事实源；本来就英文的 `verified_facts` 原样使用，不做中文回译。
  译文是机器翻译，不是费曼原话；引用原话只用 `verified_facts` 或原始英文片段。
  覆盖层检查 id/`translation_of` 对齐、字段类型、递归无中文；不做逐条人工语义校对。
  两边都不互相回退到中文，避免中英混排。PyBot 的中文输入只会落进 greeting，因此中文模式不调用它。
- Policy 与 Renderer 各带中英两套前缀/语气词，Renderer 的最近回复历史按语言分开。

## 5.6b 二阶破防与事实怀疑

- `resonance.py`：`OMEGA_RESONANCE = 2.25` 是**设计常数**，不是矩阵乘法指数的定理；
  每轮能量 = 上一轮残余按 45 秒半衰期衰减 + 本轮激活（可选怀疑钩子加成）。能量 ≥2.25 时记为突破，
  深度 2–4，扭矩 40°/单位；突破后用 `F U F' U'` 形式的短交换子写入魔方，作为反刍相位。
  突破后保留 `2/3` 阻尼再减去 20° 回弹（折算 0.5 能量）作为下一轮残余；普通轮直接携带，
  由墙钟时间继续衰减。残余能量和最后时间戳写入存档，`/api/state` 与聊天回复都带 `resonance`。
- `skepticism.py`：对“某人已证明 X”的宏大断言做窄匹配，先要 arXiv、显式构造、独立复现；
  命中时多巴胺 +0.25、皮质醇 +0.30，并注入 2.25 共振能量。对 ω=2.25 的传言明确纠正：
  已知上界约 2.37，精确值仍是开放问题，2.25 只是本程序的设计参数。

## 5.6c 右脑对左脑的策略控制

- `left_brain.py` 把本轮情绪状态折算成 `LeftBrainPolicy`：检索门槛、候选数、卡片类型偏好、
  回答详略（`brief/normal/rich`）和姿态（`answer/careful/explore`）。
- 压力/防御升高：门槛上移、偏好 `physics_edge`、答案切到 `brief`、姿态 `careful`；
  一次尖锐事件（被质疑、被教训、被提防）就能通过激活强度直接抬高 `stress`，不必等慢状态漂移；
  好奇/多巴胺升高：门槛略降、偏好 `teachable_unit`/`method_card`、可给到 `rich`、姿态 `explore`；
  精力低：候选数降为 1、答案切 `brief`。
- 阈值按真实可达的状态设定：好奇门 0.09（多巴胺 >0.64），疲劳门 0.10（精力 <0.60），
  所以一次强夸奖就能进入 `explore/rich`。每轮按激活数扣精力
  （0.008 + 0.002×激活数，封顶 0.06），长时间对话会真的累下来；休息 1 小时后向基线恢复。
- 正面角块的检索偏置取四个正面槽的平均，再过一条 tanh 灵敏度曲线（增益 1.35，输出仍封顶
  深度 ±2 / 详略 ±0.35）：首次 `R` 约 -0.195，仍在 ±0.20 门内，单个角块不会锁死详略；
  第二个离位角块即可越过门限。深度 ±1 调整候选数 ±1，详略 ±0.20 切 `rich/brief`；
  压力 `brief` 仍然优先。
- 魔方连续量也进策略（`CubeSignal` → `left_policy["cube"]`）：`displacement`（离位占比）、
  `delta`（本轮净增减块数）、`front_load`（正面离位占比）三个量都记录；只有 `delta` 改详略：
  净收回 ≥2 块（`SETTLING_DELTA`）且 `stress < 0.20`、精力 ≥0.55 时 `normal` 可升 `rich`；
  净多出 ≥2 块（`CHURN_DELTA`）时 `rich` 降回 `normal`，不降到 `brief`。零信号等价于旧行为。
- 重框（`CubeState.reframe` / `orientation`）：整体绕 y 转 90°，不改任何块的位置，
  只改变“哪一面算正面”。位移严格不变；正面增益、正面角块偏置、`front_load` 按新视角重算。
  一次成功换写类比后触发一次（冷却 `REFRAME_COOLDOWN=3`），把重评落到机械层。
- 前摄干扰（`hedge_applies`）：换话题（新卡 ≠ 上一张卡）且 `displacement ≥ 0.35` 时，
  把握线从 0.06 放宽到 0.10，`careful` 之外的姿态也可加同一句对冲；冷却 2 轮，
  只改风格句，不改 `source` 与卡片内容。
- `careful` 姿态在渲染层是真实的：丢掉口头前缀和俏皮结尾，重复也只用朴素补句；
  候选 ≥2 且第一名与第二名差距 <0.06 时，答案后加一句"把握不算大"的对冲；
  候选被压到 1 时没有可比对象，不加对冲。
- 检索层只做门槛过滤和小幅排序偏置（偏好类型 ×1.08），不能把不相关卡片抬进来；
  生成层只决定说卡片的哪些字段，不生成新事实。策略写入 `TurnResult.left_brain`、存档快照、
  `/api/state`、`/api/chat` 与 WebSocket 回复，便于观察和测试；
  本轮检索统计（`score/margin/considered`）另写入 `TurnResult.retrieval`、`/api/state` 和存档快照。

## 5.7 记忆、睡眠、关系、魔方、服务器（第 4 步）

- `memory.py`：working ≤16 / episodic ≤500（未做梦的也计入硬上限，超限时最旧的未做梦条目先丢，
  其余按显著性）/ semantic 固定模式抽事实；中文与英文各一套模式，英文值在第一个从句边界截断并过滤
  指代词（`I love it` 不建事实）；中文值和英文值都拒绝疑问词（`我喜欢什么` 不存 `什么`，
  `What do I like?` 不存 `what`）；抽事实时保留原话 `raw`；
  “我叫什么/我喜欢什么/我妈叫什么”直接从语义事实与关系图取答案，
  来源记为 `memory:semantic:*` / `memory:relations`；没写过的事实落回知识库或兜底句。
- `dream.py`：加权阈值 8（普通 1、未答上 2.5、被纠正 3.5）；叙述只引用原话；显著性并列时先用
  `Episode.affect` 的影响幅度再用轮次排序；
  晋升事实；cortisol/defensiveness/arousal ×0.55 向基线；dreams ≤50；
  `Dream.salience` 记录本批最高显著度（0..10），供引擎决定这一觉能抹平多少魔方错位；
- `relations.py`：每用户亲密度，换人时从状态读入、每轮从状态写回；trust 每轮向 affinity 缓慢靠拢
  （步长 0.05），trust <0.4 时 `tick()` 不主动搭话；中英文“我X叫/是Y”“My X is Y”都建人，
  角色统一成中文规范标签（妈/母亲/mom → 妈妈），问句里的疑问词（`我妈叫什么`）不算名字；
  `role_of` 同样规范化查询，因此中文介绍的人可以用英文问、反之亦然；
- `cube.py`：U/D/L/R/F/B + `'` / `2`，4 次同面回到原位，转完校验 26 块集合不变；
  历史里的动作可被 `parse_move` 解析回来（`'` 不写成 `3`）；
  `orientation` 记录整体视角（0–3 次绕 y 的 90° 重框），随存档保存；
  `view()` 把身体坐标映射到当前视角，`front_positions()` 按视角给出正面；
  重框不改 `occupancy`，所以位移和做梦的历史回走在任何视角下都一致；
- `cube_feedback.py`：唯一的回边，只认"离位"（出生摆位不构成偏置）。
  被移到正面的离位方块评估增益 +8%/轮，封顶 +20%，超过 3 轮疲劳 −5%/轮，下限 0.90；
  乱度比 × 0.12 抬高皮质醇基线、压低多巴胺基线一半，防御不加慢性残余；
  正面离位角块按四个正面槽平均，经 tanh 曲线（增益 1.35）压成检索深度/详略偏置（深度 ±2、详略 ±0.35 封顶），压力 `brief` 优先；
  转动门控：原始强度 <0.62 不转，已在正面者门槛 0.83，刚转过者冷却 2 轮；
  每次观察把摆位读成 `CubeSignal`（`displacement` 离位占比、`delta` 相对上轮净增减、
  `front_load` 正面离位占比），写进策略快照；`delta` 已接入左脑详略（见 5.6c），
  `displacement`/`front_load` 目前只做观测，供后续机制使用；
  做梦时沿历史逆序合法走回一部分错位；恢复比例随本批最高显著度线性下降
  （按实测标度 2.5 校准：闲聊约 0.1 要 45%，辱骂约 0.9 只给 32%，
  丧亲级别约 2.4 只给 10%，下限为基准的 20%），重要的事不会被一觉睡没；
  比例是目标不是保证：单步逆走落差可达 6 格，所以取离目标最近的可达前缀，
  若会比目标多恢复 1 格以上则宁可不走（实测 10→7、16→11、丧亲 16→16 不动），
  逆走会穿过更乱的中间态，所以先在副本上干跑，只采用真正降低错位的前缀，降不了就不动
  （梦不会把魔方转得更乱）。50 轮极端对话压力测试覆盖所有边界。
- `profiler.py`：行数、类型、缺失字段、重复 id、验证状态、语言、长度、top tags；
- `server.py`：标准库 ThreadingHTTPServer；`/` 仪表盘，`/api/*` JSON，`/ws` 最小 RFC 6455（文本/ping/close）；
- `keyframe_report.py`：40 轮脚本化实测报告，抓 verbosity 峰值与强制做梦前后的 `render_net`，
  左右并排打印；`python3 -m omega_mind.keyframe_report`，只读诊断，不进线上路径。
  单锁串行化对引擎的访问；默认绑 127.0.0.1，无鉴权。`/api/state` 暴露共振残余能量、
  左脑策略、检索统计和挑战状态；`/api/chat` 和 WS 回复带本轮 `resonance`、`left_brain` 与 `directive`；
  仪表盘只在标签页可见时每 3 秒轮询，切回时立即刷新。`serve()` 起后台线程每 30 秒 `maintenance()+tick()`；
  CLI 用 `select` 每 5 秒让出一次，空闲时间同样会做梦和主动搭话。
- 存档额外保存 `language` 和 PyBot 的 `memory`（不可 JSON 化则丢弃并标记）。
  存档是紧凑 JSON、每轮写入、临时文件 + `os.replace` 原子替换；坏档不阻止启动：
  原文件复制为 `.corrupt`，从空状态开始并在 `engine.load_warning` 记录原因。
  `event_log` 内存上限 200 条，恢复时同样截断。

## 6. 12 条验收剧本

1. 被批评：防御 >0.20，3 轮内 <0.10 且单调下降。
2. 道歉比中性回复降防御更快（差值 >0.05）。
3. 连续夸奖：增量逐次递减且为正（习惯化）。
4. 创伤词：皮质醇 >0.55，随后 2 轮 tone=cold，之后恢复。
5. 同一句挑衅：好友 warmth 比陌生人高 >0.15。
6. 冷场：满足条件只主动搭话一次；冷却后换话术。
7. 存档往返：状态、记忆、turn 号一致，可继续对话。
8. 口头禅：任意连续 5 轮中同一条 ≤2 次。
9. 费曼被纠错：多巴胺 +0.15 以上，皮质醇 <0.20。
10. 费曼遇术语：皮质醇 >0.35，tone=sharp。
11. 连续 50 轮攻击：全部维度有界；6 小时后快变量回基线，affinity 保持慢衰减。
12. 同一输入 6 轮：无逐字重复。

## 7. 事实保护

Renderer 只允许替换句末标点、加前后缀；base_reply 中的数字、名词、句子主体必须原样出现（有测试）。

## 8. 明确不做

- 不内置 PyBot 的 63 万行；通过 `bot.runtime.turn` 挂载，挂不上就用小知识库。
- 不用 `python -m pybot -p` 子进程（每轮丢记忆）。
- 不用“像不像真人”做验收；只用上面的行为断言。
