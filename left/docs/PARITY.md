与方案文本的偏离及原因：
1. **不做候选句之间的干涉**：测量结果彼此正交，两条候选句不叠加；干涉只存在于「路径自身相位 vs 观测基矢」，文档与代码注释均已写明，避免把比喻说成物理。
2. **相位取和而非取均值**：三相基矢下只有 `Σθ` 与 `3m` 可比，取均值会让心境刻度失去意义。
3. **套话用负振幅 + 硬否决双保险**：单靠负振幅在本模型里只翻 180°，与心境 180° 翻转会互相抵消。
4. **确定性采样**：原方案的 `random` 无种子，拖回同一角度无法复现；改为哈希派生种子。
5. **分词不引入 jieba**：保持离线可跑、零新依赖；代价是槽位语法性有限（印句是意象拼贴，不是完整句子），已在 README 与测试注释中说明。

### 与原始设计的偏离（都是有意的）

1. **不实时生成句子**：原设计让模型"模仿费曼写一句"。这里只做字粒拼贴，句子读起来会生硬——
   换来的是每颗字粒可核对、无一处是编造的"费曼原话"。
2. **相位偏移改为实测**：旧版把起手式 −12°、后果 +20° 当排版假设；现在按"首小句≈起手式、
   次小句≈实体、倒数第二≈动作、末小句≈后果"逐句采样，减去整句相位后取均值，得到
   `{hook −2.6°, entity −0.6°, action +1.4°, consequence +3.4°}`（±25° 内，强制单调）。
   实测结果接近 0°，说明原手编的 −12°/+20° 弧在语料里没有依据；这里保留实测值，不为了
   好看把旧弧写回去。引擎常量 `SLOT_PHASE_OFFSET` 只在字库缺字段时兜底。
3. **相位对齐改为逐槽余弦**：四槽相位和 mod 360 再比 4×旋钮会因回绕在错误旋钮上意外对齐
   （测试抓到的真实 bug），改为每槽与"旋钮+槽位偏移"做余弦后取平均。
4. **术语闸门分级**：一颗术语扣权到 0.4 倍，两颗及以上直接否决；黑名单一部分从
   `taste_discriminants.jsonl` 的 contempt 字段自动抽，一部分手工补，均不是封词表。
5. **留白优先于编造**：话题过滤后任一槽没有字粒，或 81 条路径全被否决，返回 `【此处没有可测的东西】`
   和缺口说明，不输出低置信句子。
6. **去世相关内容整段剔除**：讣告、悼念、追悼、临终、墓园、身后评价等段落（含他人写的追忆）
   在铸字阶段就被过滤，字粒只保留"他本人在说话"的语料；构建后用关键词核查，命中数为 0。
7. **句法骨架是拼装框，不是原话**：7 类骨架（陈述/条件/时间/因果/转折/由果溯因/类比）从语料
   真实匹配句计数并留出处；渲染时把四颗字粒填进框里，出来的整句在语料中不存在。骨架只负责
   "句式像费曼"，字粒才负责"词有出处"。语料里陈述句没有可匹配的关键词，`declarative` 的
   出处标注为"通用陈述框"，不冒充单一原句。
8. **骨架按语体弧定目标相位，不用语料实测相位直接排序**：语料里各句式实测相位挤在 32°–55°
   （讲义腔占绝对多数），直接排序会让比喻句通吃中高相位。改为给每类句式定目标相位
   （条件 15° / 因果 25° / 转折 35° / 陈述 55° / 时间 68° / 类比 92° / 回溯 110°），
   类比默认罚 0.6，只有"跨界"算子加权才升上来。
9. **动作按及物性调语序**：动作字粒在铸字时标 `order`，及物动词（观察/测量/吸引/想象…）渲染成
   "观察电子"，其余渲染成"电子旋转"。这解决旧版"粒子观察"这种倒装。仍是拼贴，不保证语义通顺。
10. **五个心智算子默认全 0**：微观拆解/跨界类比/极端边界/时间反演/反直觉组合只给 0–2 权重，
    默认不改变基线排序；所有算子为 0 时，权重计算与旧版逐位一致（有测试断言）。算子分数全部
    可解释：微观测的是字粒长度与具体度，跨界看日常×物理共现，边界看条件骨架与极端词，反演看
    由果溯因与共现支持，反直觉看"陌生但有据"的共现对。
11. **纯净度与枪毙清单是诊断指标，不参与采样**：`purity = 1 − 被否决路径质量 / 总质量`；
    `killed` 列出被术语枪毙的最高权重路径（最多 3 条）。它们只用于大屏核对，不改变坍缩结果。
12. **元话语黑名单在铸字期生效**：`META_DISCOURSE_NOUNS`（角度/结论/说法/情况/问题/现象/定义/
    数学/科学…）与 `META_HOOK_STOP`（事实证明/答案是/结果表明/接下来/在上一章中…）从实体、
    起手式、后果三处拦截；动作槽再拦半截词（出现什/排斥作/振荡器频）与名词短语
    （振动系统/波动理论/振动周期）。重铸后四槽 60/60/60/17，共现表 409 条（只减不增）。
13. **用户实体注入不写回字库**：`user_query` 用 `jieba.posseg` 抽 ≤3 个名词（元话语、泛化词、
    术语一律不收），作为虚拟字粒（出处标"用户提问"）只进本次请求的候选池；路径乘 1.6，
    动作按"实体或原型 × 动作"的共现判断，没共现又不在通用动作表里的扣到 0.35 倍——扣权不封杀。
    请求期绝不改写 `data/feynman_style_vault.json`（有哈希+mtime 断言）。
14. **比喻句是双槽锁**：`user_entity` 存在且骨架选中类比时，左槽只用语料实体，右槽
    "就像…"放用户名词，避免"就像咖啡杯"式自指。用户实体不传时，行为与旧版逐字节一致
