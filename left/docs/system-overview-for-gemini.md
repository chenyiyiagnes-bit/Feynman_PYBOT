# PYBOT / feynman-qbot-v2 系统说明（供外部讨论用）

> 这份文档描述的是当前运行中的系统，不是设想稿。所有数字来自本机字库与代码（2026-11-25）。
> 系统是**符号化、离散、可溯源**的排版器，不是神经网络语言模型；这点对下面"与 LLM 叠加同构"的讨论很关键。

---

## 0. 一句话定位

系统把费曼本人语料切成四类"活字"（起手式 / 实体 / 动作 / 后果），每颗字带出处、频次、语体相位；用户提问时，系统按语体旋钮和问题里的实体/谓语**筛选并拼装**这些字，套进从语料学来的句式骨架，输出一句话或一段三句。

它不生成新词、不自由改写、不调用大模型。输出中的每个实词都来自字库，每颗字都能追到原书章节。证据不足时宁可输出留白字粒，也不编。

## 1. "字粒分层"具体指什么

字粒按四个槽位分层，槽位不是语法标签，而是**生成时的组装位置**：

| 槽位 | 含义 | 例子 | 数量（当前 P15 字库） |
|---|---|---|---|
| `hook` | 起手式，负责对话姿态 | 你看 / 注意 / 我想 / 有一次 | 60 |
| `entity` | 句子的主语，被谈论的东西 | 电子 / 原子 / 电荷 / 学生 | 66 |
| `action` | 主语做的事或承受的事 | 产生 / 观察 / 碰撞 / 振动 | 60 |
| `consequence` | 可观测的结果从句 | 空间是弯曲 / 振幅减小 / 光斑变亮 | 472 |

四槽合计 658 颗字，理论组合数 60×66×60×472 ≈ **1.12 亿条路径**，但实际每次只评估几十到几百条。

字粒内部还有第二层"层级"：

- `tier`：后果槽分 tier 1（通用原子，145 条）与 tier 2（实体专属从句，327 条）；实体槽也有 60 条 tier 1 + 6 条 tier 2。选择时 tier 小的优先，即"先通用、后专属"。
- `sources`：每颗字保留 1–3 条原书出处（文件名｜章节）。
- `example`：该字在语料里的原句片段，用于审计。
- `count`：语料出现次数；`amp`：幅度权重；`domain`：`physics` / `everyday`；`style`：`lecture` / `dialogue` / `speech`；`phase_deg`：语体相位（0–120°，见下）。

另有两张关系表，不是字粒但参与打分：

- `cooccurrence`：1970 条有向/无向共现边（实体↔动作、动作↔后果、实体↔后果），来自同句/同段统计。
- `entangled_pairs`：80 对"日常实体 × 物理后果"的跨域纠缠对，语料里真的同句出现过。

## 2. 语体相位：系统的连续坐标

每颗字有一个 `phase_deg`，由它在语料句中的位置统计出来：

- 约 15°：讲义腔，黑板前一步步摆现象；
- 约 60°：对话腔，桌边打比方；
- 约 92°：类比弧，"就像……"；
- 约 105–120°：演讲/哲理腔。

槽位还有实测偏移（当前字库）：hook −3.9°，entity −1.9°，action +0.1°，consequence +2.1°。用户旋钮 `style_deg ∈ [0,120]` 加上槽位偏移，就是每颗字"应该落在"的目标相位。

打分时用**圆周余弦对齐**，不是简单差值：

```text
alignment_s = cos( phase(g_s) − (style_deg + offset_s) )
projection  = mean(alignment_s for s in 4 slots)
coherence   = 1 − |mean(e^{i·phase})|      # 四槽相位的圆周集中度
```

基础权重：

```text
weight = ((projection + 1)/2)^2 × (0.55 + 0.45 × coherence) × Π amp_s
```

这套相位/圆周统计不是装饰。它是系统里最接近"连续表示"的东西，也是后面讨论叠加时最自然的接口。

## 3. 从问句到一条路径

### 3.1 问句解析

1. **实体抽取**：jieba 词性 + 白名单/黑名单，抽名词性、非元话语、非术语的词，最多 3 个。抽出的词做成 `source="user"` 的临时字粒，注入实体槽最前。
2. **谓语抽取**：抽问句动词，排除"理解/看见/知道/观察"这类**提问方式**词（`PERCEPTION_VERBS`），其余做成动作字粒，注入动作槽最前；谓语在问句里出现在实体之前时标记为及物语序（"观察电子"），否则不及物（"电子振动"）。
3. **招呼语检测**：纯问候/自报家门走模板，不进语料排版。
4. **抽象实体判定**：股票、算法、合同这类抽象词不允许配"推动/旋转"等物理动作，改配"观察/测量/比较"等认知动作；比喻骨架对抽象实体直接禁用。

### 3.2 每槽候选

默认每槽取 3 颗 → 3^4 = 81 条路径。排序键：

```text
(tier, |phase(g) − (style_deg + offset_slot)|, −count)
```

开启条件级联（P8）后每槽放宽到 8 颗，再用**顺序束搜索**控制组合：

- 实体取 4 个；
- 动作只在"实体→动作"有共现边的候选里按边权/相位取 3 个；
- 后果只在"动作→后果"有边的候选里取 2 个；
- 起手式 4 个，最后组合成 4×3×2×4 条路径。

### 3.3 路径打分（在基础权重上逐项相乘）

| 因子 | 作用 |
|---|---|
| 对话感 | 起手式含"你/我们/想象/假设/注意/看" → ×1.25 |
| 跨域纠缠 | 日常实体 × 物理后果 → ×1.35；物理实体配对话起手式 → ×1.15 |
| 语料同句证据 | 实体×后果在 `entangled_pairs` → ×1.2 |
| 心智算子 | 8 个算子（微观拆解/跨界类比/极端边界/时间反演/反直觉/剥术语/最小作用量/货物崇拜）各给路径 0–1 分；默认全 0，乘数恒 1 |
| 拓扑层 | 三槽同句构成单纯形、测地线能量、类比空间对齐；池内归一到 1 附近 |
| 条件共现 | `cond_multiplier(entity, action, consequence)`，无证据恰好 1.0 |
| 用户实体 | 路径落在用户问的实体上 → ×1.6；动作与实体有共现 → ×1.15；无共现且非通用动作 → ×0.35；抽象实体配物理动作 → ×0.02 |
| 反馈习得 | 该实体×动作在进化库里有学到的边权 → 乘一次 |
| 术语闸门 | 命中 1 个术语 → ×0.4；命中 ≥2 个 → 权重 0（否决） |

算子融合有两种：`linear`（逐项连乘，默认）与 `boltzmann`（自由能 `exp(−Σ w_k(1−s_k)/τ)`，权重全 0 时恰为 1.0）。

### 3.4 采样与坍缩

- 随机种子固定：`seed = sha256(bank_id | style_deg | nonce | session_id | ext_hash)`。
- 存活路径按权重归一成概率；默认按概率抽样一条作为输出（"坍缩"）。
- 问句带谓语时，只在动作等于该谓语的路径里抽；若没有，退回全池。
- 条件级联下只在"最高档实体"的路径里抽，权重按概率平方，保证问句里的东西一定出现。
- 同一 seed 必得同一句；换 nonce 换一句。Discord 网关按会话轮次递增 nonce，避免每轮同一句话。

### 3.5 渲染

骨架是语料学来的句式模板，例如：

```text
{hook}，{verb}，{consequence}。
{hook}，如果{verb}，{consequence}。
{hook}，{verb}，就像{consequence}。
```

- `verb` 按及物/不及物拼成"动作+实体"或"实体+动作"。
- 比喻骨架有双槽锁：左槽放语料实体，右槽"就像……"放用户问的词，避免"就像咖啡杯"式自指。
- 骨架自带"假设"且起手式也是"假设/如果"时，换回陈述骨架，避免重复。
- 整句是拼装句：字有出处、句式有出处，但整句不是任何一句原话。

## 4. 段落编织：一次打印，三句重排

`POST /feynman/paragraph` 不调用三次打印，而是**打印一次拿 50 条候选池**，三个阶段只做筛选、重排、换骨架重渲染：

| 阶段 | 目标语体 | 骨架类别 | 连接词 |
|---|---|---|---|
| 1 现象锚点 | 用户旋钮，上限 60° | declarative / causal / conditional / temporal | 无 |
| 2 类比 | 92° | analogy | "打个比方，" |
| 3 收束 | 15° | declarative / causal / contrast | "说到底，" |

约束：

- 阶段 2、3 必须与锚点**至少两个内容槽不同**（避免只换起手式）；
- 同一段里动作不重复、起手式不重复；
- 阶段 3 优先与锚点同实体，首尾落在同一件事上；
- 连接词已经开头时，删掉该句的起手式（`drop_hook`），避免"打个比方，我们看到，……"；
- 条件级联开启时，阶段 2、3 必须与锚点同配价（及物接及物），阶段 3 必须回指锚实体；
- 凑不齐三句时逐级放宽，但不会用新文本补位。

可选的 P16"张力弧"（默认关）：给每条路径算认知张力

```text
tension = 0.55 + 0.20×相位离散度 + 0.20×触发词率 − 0.50×落地词率 + 阶段偏置
```

阶段 1 选接近 0.72 的句子，阶段 2 惩罚张力再次起峰，阶段 3 奖励"张力落差 × 与锚点相似度"。它只改候选排序，不改字粒、不造新句。

## 7. 与 LLM "叠加/重叠"的可比与不可比

先把两边说清楚，避免把一个比喻当成机制。

### LLM 那边

- 权重矩阵维度远小于特征数，特征以近似正交方向**叠加**在同一批维度上；
- "猫"和"汽车"可能激活同一组权重/方向的不同组合，产生共享与干涉；
- 表示是连续的、学习的、分布式的；意义来自几何关系，不来自符号索引。

### 这套系统这边

- 字粒是**离散符号**，每颗有唯一字符串和出处；没有学习出来的向量，没有梯度；
- 但组合空间（1.12 亿）远大于字粒数（658），所以同一颗字必然在大量不同语境里复用——这是"重叠"的字面版本；
- 复用关系目前是**索引式**的：共现表、纠缠对、tier、相位。不是几何叠加，也不会互相干涉；
- 系统里已经有一个连续坐标：`phase_deg` 与圆周统计。四槽相位可以看成四个相量，打分是相量对齐；这在数学形式上接近复数/相位表示，但相位是语料统计出来的标量，不是学习到的多维表示。

### 最自然的同构接口

如果要把"叠加"真正做进这套系统，有三个层次，代价和风险递增：

1. **相位即复表示**：把每颗字从标量相位升级为二维复向量（或低维相量），路径分数用内积而非逐槽余弦平均。字粒仍是离散符号，但"同一颗字在不同语境下的不同面向"可以用不同投影表达。可逆、可解释、不造新文本。
2. **共现即低秩叠加**：对 1,970 条共现边做 PPMI/SVD，得到每颗字的低维上下文向量；用双线性兼容度替代手工乘数。这会产生真正的"猫与汽车共享维度"现象，也能捕捉当前最明显的缺陷——实体漂移（P16 里"半径发光"这类路径）。
3. **路径叠加态**：不立刻坍缩到一条路径，而是保留 Top-k 的加权混合，再按温度/证据坍缩；或者把"叠加"用于候选打分而非输出文本，避免拼出无法读的混合句。

### 必须守住的约束

- **不造新文本**：任何新机制只能重排、加权、筛选现有字粒；输出的每个实词仍须能溯源。
- **确定性**：同一 seed 必须可复现；随机只用于坍缩，不用于生成。
- **留白优先**：证据不足时输出留白，不用语言模型补句。
- **不得引入推理期外部模型调用**：这是产品约束，不是技术偏好。
- **可审计**：新增分数要能落到字段（像现在的 `projection` / `coherence` / `operator_scores` / `topology`），否则无法回归。

## 8. 给讨论者的几个具体问题

1. 用相位/复向量表达字粒的"语境面向"，是否比现在的标量相位更能解释同一颗字在不同句子里的不同角色？
2. 低秩共现嵌入能否在不引入新文本的前提下，预测"哪颗后果字适合哪个实体"，并超过现有 tier + 共现边规则？
3. "叠加态 → 坍缩"应该只发生在打分层，还是也可以发生在输出层（例如给用户两个候选句而不是一句）？
4. 如果要检测"猫与汽车共享同一权重"式的干涉，最小编译单位应该是什么：字粒、槽位、骨架，还是整条路径？
5. 这套离散系统的组合爆炸，与 LLM 的叠加容量，是否存在可量化的对应关系（例如有效维度 vs 有效路径数）？
